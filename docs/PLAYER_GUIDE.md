# 《战线 · 战役指挥》玩家手册

> 面向玩家的完整教程与规则说明。游戏内「指挥手册」为精简版；本文是维护中的权威手册。  
> 更新基线：`codex/first-playable`（含结算简报、控制区、交战预估等）。

---

## 1. 这是什么游戏

Windows 中文 **2D 六角格作战级兵棋**。

- **WEGO**：双方各自下令并锁定，然后**同一时刻**结算六个战术时段。你无法在对手行动中途反应。
- **不完全情报**：只能看到己方完整状态，以及被侦察到的敌军（无精确兵力）。
- **数据驱动剧本**：七个场景（1 教学 + 6 历史），地图抽象但保留关键地理矛盾。

定位是「图册风指挥决策」，不是精确历史复原。数值与部署均为可玩设计。

## 2. 快速上手（10 分钟）

1. 主菜单选择 **沙盘入门**，模式选 **人机对战**，阵营蓝方，难度 **标准**。  
2. 点击左侧 **战斗序列** 或地图上的己方算子选中单位。  
3. 点 **机动**，再点地图目标格；观察金色 **路径预估**。  
4. 给 1–2 个单位下令后点 **锁定命令 · 结束回合**。  
5. 阅读 **战役结算** 简报（交战、积分、易手），点 **继续指挥**。  
6. 打开 **战报** 看积分时间线与损耗；需要时 **导出战后报告**。

教学关分步目标已写在剧本简报里：选中 → 下令 → 过桥 → 支援 → 锁定。

## 3. 界面地图

| 区域 | 作用 |
|---|---|
| 顶栏 | 标题、回合、天气、积分、战报、菜单 |
| 地图 | 六角格；拖动平移、滚轮缩放 |
| 图层 | 地形 / 控制 / **控制区（ZOC）** / 补给 |
| 侧栏 | 单位档案、战斗序列、回放 |
| 底栏 | 八种命令、姿态、清空命令、锁定回合 |

**图例**

- 蓝/红算子：阵营（敌方带斜线，便于色觉区分）  
- 金色圆环：战略目标  
- 虚线箭头：已下达命令  
- 金色折线：路径预估  
- 红晕：敌方控制区  
- 右下金角：该单位**尚未下令**  
- `?`：历史接触（可能已过时）  
- 地名标签：剧本中的真实地名抽象

## 4. 六种核心资源

打开单位档案时注意：

| 字段 | 含义 | 读法 |
|---|---|---|
| 兵力 | 有生力量 | 归零即损失 |
| 组织 | 战斗意志/队形 | 过低会溃退 |
| 疲劳 | 累积消耗 | 过高降速与战力 |
| 燃料 | 机动单位油料 | 耗尽无法继续机动 |
| 弹药 | 交火消耗 | 过低战斗力下降 |
| 补给 | 后勤连通 | 充足 / 紧张 / 断绝 |

**筑城**：固守/预备/工兵会提高；机动会清零。  
**指挥延迟**：远离总部时命令可能延迟数回合才执行。

## 5. 命令一览

| 命令 | 快捷键 | 说明 |
|---|---|---|
| 机动 | 1 | 向目标格移动；道路更快，复杂地形更慢 |
| 进攻 | 2 | 向敌所在格突击；同时回合下可能与敌对撞 |
| 固守 | 3 | 原地提高筑城，防御加成 |
| 休整 | 4 | 恢复组织、降低疲劳（需补给） |
| 侦察 | 5 | 扩大视野，改善敌情 |
| 预备 | 6 | 保持弹性，不轻易前推 |
| 撤退 | 7 | 向后方/补给方向脱离 |
| 工程 | 8 | 仅工兵：在河流格或邻格架桥 |

**姿态**：谨慎（攻弱守强）/ 均衡 / 积极（攻强守弱，更易硬拼）。

命令会**持续执行**，锁定前可改。  
**清空命令**：清本方全部未锁定命令。  
**Backspace**：撤销选中单位命令；**Shift+Backspace**：全部清空。

## 6. 同时回合（WEGO）怎么想

1. **先判接触**：谁可能在下回合进入射程/控制区？  
2. **再判补给**：油料与补给是否支撑深入？  
3. **预估赔率**：选「进攻」后悬停敌格，看 **交战预估** 与接触面。  
4. **不要平均用力**：集中 2–3 个单位打一个要点，比全线平推更有效。  
5. **留预备**：至少 1 个单位不要全部投入第一波。

你看到的「交战预估」按**接触面（frontage）**折减，与真实结算同构；多路夹击通常更有利。

## 7. 控制区（ZOC）

敌方战斗单位（非指挥部/后勤/炮兵）周围 **1 格** 为控制区。

- 进入控制区：**本回合停止机动**（会吃一格，然后锁死）。  
- 图层「控制区」用红晕标出。  
- 路径预估若会停步，会提示「进入控制区将停止机动」。  
- 补给路径也会避开敌控制区——切断补给是重要战法。

**用法**：用控制区「托住」敌装甲；或用步兵控制要道，掩护装甲绕开。

## 8. 战斗如何发生

在六步结算中，单位若：

- 移动意图在同格相遇、对穿，或  
- 相邻且有「进攻」命令  

则进入交火。战力受：兵种、兵力、组织、疲劳、弹药、补给、地形、姿态、筑城、步坦协同、邻接炮兵、天气/夜暗、反坦克与时代规则影响。

交火会掉兵力与组织；组织过低或兵力过低会**退却**。  
成功突击且目标格清空时，可能 **突破占领**。

结算结束后：

- 日志中有各单位「交战汇总」  
- **战役结算**简报按行展开本回合要点  

---

## 9. 补给与后勤

- 己方 **补给枢纽（depot）** 在补给图层显示。  
- 单位沿可通行格追溯补给；敌控制区、无桥河流、山地会抬高代价或切断。  
- 补给断绝：组织恢复差、战斗力下降，AI 与你都应考虑撤向枢纽。  
- 炮兵支援需要射程内且弹药充足。

---

## 10. 火力支援

每方每回合 **一次** 战役支援（单位档案右侧）：

| 类型 | 作用 |
|---|---|
| 炮火 | 打击已知敌集群；需己方炮兵在射程内 |
| 空援 | 受时代与天气限制 |
| 侦察 | 揭示目标附近敌军 |

支援落点会在地图上画出标记。  
**AI**：看见敌集群会打炮/空援；全盲时会用侦察开图。

---

## 11. 天气与夜暗

- 地形图右上角显示当前天气。  
- 部分剧本有 **天气表轮转**（雨/雾/风暴/夜暗）。  
- 恶劣天气降低机动与视野；夜暗对二战部队更不利（现代夜战能力更强）。  
- 西奈等剧本启用昼夜循环。

---

## 12. 胜利条件

- **占领目标得分**（失守会扣回），不是「每回合占着就无限刷分」。  
- 回合耗尽比总分；或一方全灭。  
- 战报有 **积分时间线** 与 **目标易手** 记录。

## 14. 模式

| 模式 | 说明 |
|---|---|
| 人机对战 | 对离线 AI；可选简单/标准/强硬 |
| 同机轮换 | 热座；交接遮罩保护双方命令 |

## 16. 回放、存档与战报

- **回放**：侧栏 ←/→ 或时间轴滑条，只读历史快照。  
- **存档**：slot1–3 + 自动档；存档管理可读/覆盖/删除。  
- **战报**：目标、易手、积分时间线、损耗榜、最近行动。  
- **导出战报**：写入 `after_action_report.txt`（含模式/难度/剧本/种子等对局参数）。

## 17. 结算简报

每回合锁定结算后，若开启简报（菜单可关），会弹出 **战役结算** 面板：

- 回合与天气  
- 积分与本回合变化  
- 交战（按损失排序）  
- 目标易手 / 火力支援 / 增援 / 战场动态  
- 战役结束时的胜负原因  

点「继续指挥」或点空白处关闭。

## 18. 进阶思路

1. **侦察优先**：不知道敌在哪就不要全军压上。  
2. **控制区当墙**：用步兵顶住，装甲从缺口或侧后卷击。  
3. **算油料**：现代剧本纵深大，断油比断粮更致命。  
4. **姿态切换**：谨慎试探 → 积极突破 → 固守消化。  
5. **工兵架桥**：河线剧本改变机动轴。  
6. **读简报**：每回合结算比地图动画更重要。

## 19. 常见问题

**Q：点了目标但单位没动？**  
检查：指挥延迟、燃料、组织过低、ZOC 停步、路径不可达（会有警告）。

**Q：为什么看不到敌军兵力？**  
战争迷雾只给强度带（强/中/弱）；需要侦察或接触。

**Q：占了目标为什么分数不涨？**  
分在占领/易手时结算；持续占领不重复刷分。

**Q：LAN 客人命令像没生效？**  
以主机裁决为准；断线后用房间票据重连。

**Q：如何关闭结算简报？**  
对局菜单 → 关闭结算简报。
