# EWarGame / 战线 · 战役指挥

Approved in conversation: Windows Chinese 2D hex operational wargame; regiment/brigade/division counters; WEGO secret simultaneous orders; three eras and six scenarios plus tutorial; hotseat, LAN and offline AI; MCP plus Skill. User explicitly removed real local Agent acceptance from this release. MCP protocol/permission tests remain required. No implementation needs further approval within this scope.

## Product
Map-first atlas aesthetic, cream paper / charcoal panels / muted blue and vermilion counters, original vector terrain. Pan/zoom, selection, orders, overlays, rosters, intelligence, after-action reports, save/load and replay. Each scenario fixes hex and turn scales. Different historic abilities, not merely country-colored stats. Sources distinguish documented formations from designed strengths, maps and victory scoring.

## Rules
Orders: move, attack, defend, rest, recon, reserve, retreat, engineer; targets use axial q,r coordinates; stances cautious/balanced/aggressive. Persistent orders. Six substeps per simultaneous turn, seeded deterministic random; opposing movement/encounters handled together. Terrain movement, roads/rail, bridges/rivers, control, entrenchment, frontage, combined arms, readiness, fatigue, finite fuel/ammunition, throughput-limited supply tracing, headquarters command distance/delay, support allocation, weather/night, fog of war and dated contacts. Casualties, retreats, recovery, reinforcements, scenario objective scoring. Era capabilities modify reconnaissance, air/air defense, antitank and command/supply factors. No side may query hidden orders, random state or exact hidden enemy strength through UI/network/MCP.

## Architecture and stable interfaces
Godot 4.7.2. Core scripts are RefCounted, UI calls GameSession autoload only. Authority owns full game; public observations serialized to clients. Local MCP stdio bridge connects to authenticated loopback command service. Saves versioned JSON with full state and snapshots; writes atomic. No live local Agent match acceptance. Actual dual-machine LAN remains distinct from same-machine process tests.
