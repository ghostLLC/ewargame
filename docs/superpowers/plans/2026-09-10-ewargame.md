# EWarGame Implementation Plan

> For agentic workers: Use superpowers:subagent-driven-development for independent component work, with integration and review by the primary agent.

**Goal:** Deliver the approved Windows WEGO wargame and adapters.
**Architecture:** One Godot rules authority, side-projected UI/network/MCP. Scenario content is data-driven.
**Tech Stack:** Godot 4.7.2, GDScript, Node.js stdio MCP, original vector artwork.
**Spec:** ../specs/2026-09-10-ewargame-design.md

## Global Constraints
- Windows Chinese 2D hex operational wargame; numeric sides 0/1, axial coordinates.
- WEGO secret simultaneous orders and deterministic adjudication.
- Three eras, six scenarios plus tutorial; hotseat, LAN, offline AI, MCP and Skill.
- User explicitly removed real local Agent acceptance from this release.
- Follow stable interfaces in the spec; each owner edits only its assigned files.
